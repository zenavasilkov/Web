## 📋 Project Overview

A fully responsive landing page for the **HSE Art and Design School**, built with CSS techniques including **Grid**, **Flexbox**, **media queries**, and **CSS animations**.

The website adapts seamlessly across all device sizes:
- 🖥️ **Desktop** (≥1200px)
- 📱 **Tablet** (768px)
- 📱 **Mobile** (320px)

## ✨ Key Features

### 📐 Responsive Layout (Lab #4)
- ✅ Modular CSS architecture (split into logical component files)
- ✅ CSS Grid for complex layouts (news, resources, banners)
- ✅ Flexbox for flexible components (header, footer, cards)
- ✅ Media queries at breakpoints: `1200px`, `992px`, `768px`, `480px`
- ✅ Relative units: `%`, `vw`, `clamp()`, `rem`
- ✅ No horizontal scrolling at widths <320px
- ✅ Verified with PerfectPixel and Chrome DevTools
